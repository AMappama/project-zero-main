# 术语

冻结以下用词。每个词只在这里定义一次。不把别的叫法收成同义词。

**服务实例**  
一笔订单在履约库里的那一行。上面有状态，也有计划开始日、起止、总结束和四类次数。

**服务归属**  
这个会员当前这一位服务人。角色只能是服务。一行要么有效，要么已经停用。

**待启用**  
服务实例还没有开启时的状态。条件不够，或计划开始日还没到，就停在这里。

**启用中**  
服务实例已经开启、这一单正在服务时的状态。身份按全部实例计算时，只要有一笔是这样，这个人就是 VIP。

**暂停**  
服务实例在暂停申请通过之后的状态。通过时结束日和总结束日不改。身份计算里，这一档高于另一笔只是待启用。

**失效**  
退费完成后服务实例的状态。它不是做完了服务。

**完成**  
关单两级都通过之后服务实例的状态。

**待判断**  
红娘打开工作台先看的一块：待确认的推荐、到点还没填的见面结果、系统因到期或恋爱起草且尚未审核的关单、以及只建议关单还没有申请的那一条。

**例外**  
红娘工作台上的另一块：还不能开启的缺口、服务人落到店长或总监、以及这一单要暂停、要赠送、要提前关单或可以提前恢复。

**审核**  
审核人工作台上的一块：赠送待审、暂停待审、关单一审、关单二审。赠送和暂停各审一次。关单要两级，一审不改服务实例。

**红娘**  
账号上的一项权限。有这项的人看待判断和例外，可以指定服务人、确认推荐、记约会、发起暂停赠送和关单、领取过期会员。林晓只有这项。

**审核人**  
账号上的另一项权限，只加在已经有红娘权限的账号上。有这项才看审核，并通过或驳回赠送、暂停和两级关单。苏衡两项都有。没有只带这项的账号。

**推荐草稿**  
任务表里种类为推荐草稿、状态为待确认的一行。它还不是推荐事实。确认之后才写入推荐，并不改成熟度。准备时只用已经在新库里、且已在该红娘服务库中的会员。

**约会**  
约会表里的一行，记这一场的时间、地点、对象、双方状态、结果和反馈。对象是库内会员，或只有外部姓名。结果只写在这一行上。

**过期 VIP**  
一个查询结果，不是一张池表。要同时有已完成的服务实例、已通过且记了是否同意、原因、关单人、关单前服务人的关单，并且当前没有有效的服务归属，也没有关单之后的销售或邀约领取。

**到期函**  
`close_vip_contract` 里的一行，记下这单的到期通知。写入它不改服务实例，也不代替关单。
