GLOSSARY

冻结用词 · 一词一义

06 / 08

服务实例

一笔订单在履约库里的那一行：状态、计划开始、起止、总结束、四类次数。

服务归属

当前这一位服务人。角色只能是服务；要么有效，要么已停用。

待启用 / 启用中

未开或已在服。任一启用中 → 身份 VIP。

暂停 / 失效 / 完成

暂停通过后；退费后失效（≠完成）；两级关单通过后完成。

待判断 / 例外 / 审核

工作台三块。审核只给有审核权限的账号。

推荐草稿

任务表待确认行，还不是推荐事实。确认后才写推荐。

过期 VIP

查询结果，不是池表。完成实例 + 齐全关单 + 无有效服务归属。

到期函

`close_vip_contract` 一行。不改实例，也不代替关单。

不把别的叫法收成同义词。完整定义只在 `docs/glossary.md`。
STATE MACHINES

四条各记各的

07 / 08

服务关系

无有效归属 → 有效归属 → 无有效归属

指定 / 默认（matchmanager→店长→总监）/ 红娘领取进有效。关单二审通过或退费完成（归属即本单）退出。

牵线单

无牵线 → 待确认 → 已确认

草稿在任务表，事实在推荐表。确认不改成熟度、不改约会。同会员同嘉宾不能第二条。

约会单

无约会 → 结果空着 → 已写结果

结果只写在这一行。恋爱默认只产生关单建议，不把实例改成完成。

服务期

未写起止 → 已写起止 → 延长 / 重算

开启写起止与总量。暂停不改日期；恢复按剩余月重算。一期不扣已用。

身份不是第五条状态机。按全部服务实例固定顺序计算，缓存列禁止手改。
不许发生：销售/邀约写成服务归属；恋爱直接完成实例；暂停通过改结束日；草稿阶段插入推荐事实。

现行 → 目标 · 已落地

08 / 08

现行习惯

  • 开启：指定红娘后人手点开启，写多表与小记
  • 关单：通过后写过期池、诚意库、节点小记
  • 推荐：直接写 mark，常改成熟度
  • 身份：人手可改的会员类型字段

牵线宝目标

  • 开启：四项满足系统开；无旧按钮
  • 关单：两级审；不写池表与诚意库
  • 推荐：先草稿，确认后才写事实
  • 身份：只按实例查询，禁手改
