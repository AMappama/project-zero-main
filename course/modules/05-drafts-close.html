}

暂停和赠送只审一次

暂停通过只把实例改成暂停，结束日先不动。赠送通过只延长结束日或增加某一类总量，已用不动。

恋

恋爱不等于关单

默认只写「关单建议」，不建申请。打开自动起草后才会起草，仍然不自动审核。

暂停像月票，不满一个月不算用过

服务月按日历月计。某一服务月只有在暂停日不早于该月最后一天时，才算走完。暂停了多久再恢复，都不把暂停天数加回原来的结束日。新的结束日 = 恢复日 + 暂停时记下的剩余月数。

6 个月 1 月 1 日开始。2 月最后一天暂停：走完 2 个月，剩下 4 个月。
恢复日 + 4 哪怕停了很久，剩下的仍是 4 个日历月，从恢复那天往后加。
已用不动 赠送和暂停都不改已用次数。这一期本来也不扣已用。
代码 
export function remainingServiceMonths(start: string, pauseDate: string, durationMonths: number): number {
  if (durationMonths < 1) {
    throw new Error("服务时长至少要有一个月");
  }
  return durationMonths - elapsedServiceMonths(start, pauseDate, durationMonths);
}

跟 AI 说「按日历月，不满月不折算」

如果它写成「暂停天数加回结束日」，那是另一套产品。这个账本不这么算。处理中名单只包含还没审完的申请：关单的待审和待二审，以及赠送、暂停的待审。通过之后就离开处理中。
